## Updating commands

When updating Telegram commands, update the block below and set it via [BotFather](https://t.me/BotFather) by running `/setcommands` command:

```
register - Register the member in the ledger
withdraw - Withdraw the member from the ledger
join - Join finances with a member (example: "/join @kossnocorp")
separate - Separate a member from joint finances (example: "/separate @kossnocorp")
give - Give money to a member (example: "/give @kossnocorp 100 USD - Cash for groceries")
borrow - Borrow money from a member (example: "/borrow @kossnocorp 100 EUR - Cash for groceries")
expense - Add an expense to the ledger (example: "/expense 100 EUR - Airbnb in Prague")
balance - Calculate who owes whom
history - Print the actions history
members - Print the ledger members structure
relief - Cancel member's debt (example: "/relief @kossnocorp")
currency - Set the default ledger currency (example: "/currency SGD")
```
